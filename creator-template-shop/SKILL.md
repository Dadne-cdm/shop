# Creator Template Shop — SKILL.md
> Skill para construir temas Shopify premium completos desde cero, replicando la calidad y estructura de **Pipeline (Groupthought)** e **Impulse (Archetype Themes)**.

**Versión:** 2.0  
**Última actualización:** Mayo 2026  
**Referentes de calidad:** Pipeline 8.1.1 + Impulse 9.0  

---

## Cuándo usar este skill

Usar cuando el usuario quiera:
- ✅ Crear un tema Shopify completo desde cero (OS 2.0/3.0)
- ✅ Generar secciones Liquid (.liquid) para cualquier página
- ✅ Configurar schemas JSON de secciones y bloques
- ✅ Crear snippets reutilizables y theme blocks
- ✅ Construir templates (.json) para Online Store 2.0/3.0
- ✅ Producir archivos listos para subir a Shopify via Theme Editor o Shopify CLI
- ✅ **Clonar/replicar una sección o página a partir de captura de pantalla** (Modo Agente Visual)
- ✅ Integrar apps externas (Loox, Recharge, Appstle, Klaviyo, Judge.me, etc.)
- ✅ Replicar funcionalidades Premium de Pipeline e Impulse

**Nicho principal:** suplementos / health & wellness (aplica a cualquier tienda DTC).

### 7. TRADUCCIÓN DE CONTENIDO — ESTRATEGIA

**Fase 1: Rápida (Día 1-7)**
- IA auto-translate 100% contenido
- Weglot, Transcy, EA Auto Language
- Costo: $0-50/mes

**Fase 2: Validación (Semana 2-4)**
- Revisar manualmente TOP 20 páginas
- Home, Product pages, Checkout, FAQs

**Fase 3: Escala (Mes 2+)**
- Traducir últimas páginas con human review
- Mantener translations actualizadas (nuevos productos)

**NO hacer jamás:**
- ❌ Traducir código Liquid (rompe funcionamiento)
- ❌ Traducir URLs sin hreflang tags
- ❌ Mezclar idiomas en página misma

## 🐛 TROUBLESHOOTING ERRORES COMUNES

### Error: "Liquid syntax error"
**Causa:** Sintaxis Liquid inválida (brackets, filters)
**Solución:**
```liquid
❌ {{ product.title | upcase }}
✅ {{ product.title | upcase }}
```

### Error: "Section schema is invalid JSON"
**Causa:** JSON mal formado en schema
**Solución:** Validar JSON en jsonlint.com

### Error: "Undefined variable"
**Causa:** Variable no existe
**Solución:**
```liquid
❌ {{ undefined_var }}
✅ {% if undefined_var %}{{ undefined_var }}{% endif %}
```

### Cart drawer no abre
**Causa:** JavaScript no cargado o selector incorrecto
**Solución:** Validar que assets/theme.js está correctamente enlazado

### Imágenes se ven pixeladas en mobile
**Causa:** Imagen no responsive
**Solución:**
```liquid
❌ <img src="{{ image | image_url }}">
✅ <img src="{{ image | image_url: width: 500 }}" 
        srcset="{{ image | image_url: width: 500 }} 500w, 
                {{ image | image_url: width: 1000 }} 1000w">
```

### Language selector no funciona
**Causa:** Hreflang tags o localStorage no configurado
**Solución:** Verificar que Shopify Markets esté habilitado en admin
